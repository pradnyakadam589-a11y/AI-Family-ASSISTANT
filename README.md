# AI Family Assistant System

## Project Overview
The AI Family Assistant System is a simple Python project designed to help families manage tasks, events, and daily activities.

## Features
- Ask the family assistant simple questions.
- Add and view family tasks.
- Add and view family events.
- Get family activity suggestions.

## Technologies Used
- Python
- Visual Studio Code

## Concepts Used
- Functions
- Lists and dictionaries
- Conditional statements
- Loops
- Keyword matching

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `python family_assistant.py`.

## Limitations
This project uses rule-based keyword matching. Tasks and events are stored temporarily while the program is running.
